A structured collection of **100 Core Java interview questions**, covering fundamentals through concurrency. The material includes detailed answers, real-world use cases, and Java code examples to support interview preparation and revision.

## Who This Is For

- Java developers preparing for interviews
- Candidates with 3–8 years of experience
- Learners reviewing Core Java concepts
- Developers looking for practical examples and use cases

## How to Use

1. Start with **Part 1** and review each question in order.
2. Understand the detailed explanation and real-world use case.
3. Run the code examples locally.
4. Attempt the questions from memory before reviewing the answers.

## Example Topics Covered

- JVM, JRE, JDK, and platform independence
- Object-oriented programming principles
- Strings, wrappers, exceptions, and serialization
- Collections and generics
- Lambda expressions and functional interfaces
- Streams and Java 8 features
- Threads, synchronization, locks, and concurrent collections
